# Optional local artwork

The public source intentionally contains no Call of Duty game artwork. The app runs with labeled placeholders when artwork is absent; it never fetches images from the internet.

For your own private build, place only images you are entitled to use in this directory, matching the filenames in `src/renderer/catalog.mts`. The original private sample recognizes `cpu.png`, `detonators.png`, `nylon-cloth.png`, `power-regulator.png` and `reactive-metals.png`. Keep provenance and permission records with your private copy.

These files, runtime bundles and private profiles are excluded from Git. Attribution alone does not grant redistribution rights. The source-code license does not license game names, images or third-party materials.
