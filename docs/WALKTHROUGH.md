# Quick-start video

The Windows 0.1.9 release includes a short narrated walkthrough recorded from the actual packaged app, using an isolated synthetic board. It covers choosing printer goals, tracking pickups, Have it / Want it / Neither, the wanted vest on the Raid checklist, bulk selection, New raid and backups. Highlight outlines and chapter headings were added during editing. The app footage is not a generated mockup and contains no owner inventory, account information or desktop capture.

[Watch or download the video](https://github.com/drakahari/dmz-raid-board/releases/download/v0.1.9/DMZ-Raid-Board-Quick-Start-0.1.9.mp4). The release also includes SRT and WebVTT captions and a plain-text transcript; captions are visible in the video itself. The MP4 uses H.264/AAC for ordinary Windows playback. Extract the application ZIP separately; the video is a release asset, not an application dependency.

Narration uses the historical DLMS settings supplied by the owner: **Kokoro 82M, voice `af_heart`, speed `1.0`, US English**. The same voice was restored locally using the free [kokoro-onnx runtime](https://github.com/thewh1teagle/kokoro-onnx) and the maintainer's full-precision v1.0 model and voice bundle. No substitute voice, paid API or new credentials were used. The runtime is MIT licensed and the [upstream model](https://huggingface.co/hexgrad/Kokoro-82M) is Apache-2.0 licensed. Model and voice hashes, media checks and exact runtime information are attached in VIDEO-CHECKS.json. No model files or Python dependencies are distributed with the app.

The workflow records local app interactions, retains their timing, adds chapter text and focus outlines, combines the eight narration segments, normalizes speech loudness, and encodes a 1080p MP4 with FFmpeg. A short still hold can be extended to fit narration; no app state or result is fabricated. The reviewed narration text is in WALKTHROUGH-SCRIPT.json. The final media is checked by complete decoding, caption comparison, audio-level analysis and real Chromium playback with chapter seeks. Automated speech recognition is a secondary content check, not a substitute for listening.

Game artwork visible in the footage retains its existing third-party rights limitations. It is outside the application's MIT code license; credit does not establish permission or endorsement. See THIRD-PARTY-ARTWORK.md and the image-source notices attached to the release. This release contains Windows x64 only; it makes no new macOS or Linux verification claim.
