# DMZ application icon

The DMZ sibling icon is adapted from the owner-selected DLMS round badge, with DMZ lettering and a distinct lime accent. DLMS source is used read-only; no DLMS project files are changed. The app icon is separate from Activision game artwork.

Reference: [DLMS icon master and recorded owner authorization](https://github.com/drakahari/DLMS_next/blob/main/desktop_assets/ICON_PROVENANCE.md). That source records the owner authorization separately from the code license and does not invent a license from the original unknown image generator. The owner requested this DMZ adaptation and its distribution with this app.

`dmz-icon.png` is the retained raster master. Electron Builder converts it to platform icon resources; the same image is used as the BrowserWindow icon. Mechanical resizing/format conversion does not redesign the artwork. Native taskbar/Dock visual acceptance is distinct from packaged resource checks.
